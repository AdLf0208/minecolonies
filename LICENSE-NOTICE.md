- **Licence:** GNU GPL v3 **or later**, the same terms as the original code. The full text is in

- **Corresponding source:** published with the port (this repository: the Rust sources under
  `src/`, the generators under `tools/`, and the generated content under `assets/` and `data/`).
  The `.hmod` package also carries this notice and the licence text, beside `src/`, `assets/` and
  `data/`, so the source travels with the artifact.
- **What it is:** a clean-room Rust rewrite of a slice of MineColonies' behaviour (a town hall
  founds a colony, one citizen takes the farmer's job, `/minecolonies colony|citizen|job`), written
  from reading the upstream sources. It is not a translation of the Java code and contains none of
  it.

  mod's **ids** (`blockhuttownhall`, `blockhutfarmer`, `scythe`, the `citizen` entity type) and
